# Define the destination and scope

Type: `grilling`
Status: `resolved`
Blocked by:

## Question

What artifact should this effort produce, and which parts of MarkText are inside or outside the Typora-inspired redesign?

## Answer

The destination is an implementation-ready specification, not implementation mixed into the Wayfinder map. It covers the application shell and workspace layout: title bar, sidebar, tabs, editor framing and spacing, status information, responsive behavior, and the functional state transitions behind those regions.

The document theme is excluded. Typora is evidence for visual hierarchy and behavior, but the result must be an independent implementation and must not copy proprietary code or assets.
